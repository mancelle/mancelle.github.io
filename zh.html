我们预训练了 Mancelle-3B：一个带有控制通道的语言模型，这个通道与输入文本相互分离。通过它引导，效果强且回复保持流畅。当攻击者控制输入文本时，这种引导在黑盒和白盒对抗提示下依然有效，而这些提示能击溃事后引导方法。

摘要

我们的目标是构建从设计上就可引导的语言模型。如今的语言模型用下一个 token 预测进行预训练，对齐和控制只能留给最后 1% 的训练 token，或推理时的干预。这些模型用同一个输入通道同时承载指令和数据，导致常见的失效模式：模型把数据误当作指令，例如有意的越狱，以及无意的上下文对齐漂移。

为此，我们提出一种从一开始就把两者分开的预训练方法和架构，得到 Mancelle-3B。一个编码器处理即将出现的文本的高层语义特征，交叉注意力使 token 流无法反向写入这个控制通道。预训练中，模型学会依靠这些特征预测下一个 token，从而让这个通道成为引导模型的有效抓手。

在可比的开源模型上，Mancelle-3B 的引导比基于提示和基于激活的方法更强，同时保持流畅；它还能抵御能击溃这些基线的黑盒和白盒对抗性反向引导。我们用 Mancelle-400M 在一个控制更严格的基线上复现了这一结果。我们的结果表明，只要尽早且有意地去做，鲁棒的控制可以内建到语言模型中。

鲁棒性

对黑盒和白盒对抗提示鲁棒

我们评估面对对抗者时的鲁棒性：对抗者通过优化的黑盒提示和白盒软提示控制模型输入。黑盒攻击者只能看到被引导模型的回复，白盒攻击者则可以对软 token 求梯度。

另有两种输入也会进入控制通道：提示的 SAE 特征，以及每一段对下一段的特征预测。引导会把每个预测出的信号移向目标；强度为 6 时，信号完全由目标决定。

黑盒优化的提示后缀

所有方法，50 个概念

两种黑盒攻击器在每条指令后附加一个后缀，试图去掉被引导的概念：GEPA 在一个反思型 LLM 提出的后缀中搜索；另一个是用强化学习训练的攻击模型。Mancelle-3B 分别保留了 92% 和 97% 的概念分。最有效的事后方法也最脆弱：在 Qwen2.5-3B 上，RL 攻击器在 39 个被引导的概念中破坏了 Prompting 的 37 个，而对 Mancelle-3B 只破坏了 37 个中的 2 个。

白盒基于梯度的软提示

所有方法，50 个概念

能获取梯度的攻击者优化附加在指令后的四个软 token。使用自由软 token 时，Mancelle-3B 在 Conditioning 和 NL Steering 下都保留了 81% 的概念分，被攻击后的分数（1.06 和 0.97）仍高于所有基线方法（最高 0.60）。限制为真实 token 的混合时，它分别保留 91% 和 92%。

局限性

能力。Mancelle-3B 的 ChatCORE 分数为 0.317，用相同后训练数据训练的 Pythia-2.8B 为 0.338。我们将其归因于近十个 epoch 的数据重复。

数据处理。为预训练数据标注特征要花掉 5–10% 的计算预算，Mancelle-3B 的压缩数据集占 2.7 TB。

威胁模型。攻击者控制的是输入 token。直接写入模型内部的攻击，例如在残差流中做加性引导，对我们引导的削弱程度与对事后引导的大致相当。对抗者也可能通过操纵输入 token，对抗性地改变模型自己预测的特征。
