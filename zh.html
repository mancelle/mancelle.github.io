Steerable by Design: Conditional Pretraining for Robust Control of Language Models

○Cambridge-Boston Alignment Initiative ◇MIT △Harvard University *共同第一作者

语言模型通过同一个输入同时接收指令和数据，所以输入里的文字就可能推翻对模型的控制。我们预训练了 Mancelle-3B，给它一条独立的控制通道，并用它来 steer 模型：steering 效果强，回复依然流畅；能让 post-hoc steering 失效的黑盒和白盒对抗 prompt，也去不掉它。

工作原理

摘要

我们的目标是构建从设计上就可 steer 的语言模型。如今的语言模型用 next-token prediction 预训练，对齐和控制只能放在最后 1% 的训练 token 里，或者靠推理时的干预。这些模型用同一个输入通道同时接收指令和数据，于是常常把数据误当成指令，比如有意的越狱，以及无意中在上下文里发生的对齐漂移。

为此，我们提出一种从一开始就把两者分开的预训练方法和架构，训练出 Mancelle-3B。一个编码器处理接下来文本的高层语义特征，再通过 cross-attention 交给模型，而 token 流无法反过来写入这条控制通道。预训练中，模型学会依靠这些特征预测下一个 token，这条通道也就成了 steer 模型的有效抓手。

在规模相当的开源模型上，Mancelle-3B 的 steering 比基于 prompt 和基于激活的方法更强，同时保持流畅；能击溃这些基线的黑盒和白盒对抗性反向 steering，它也扛得住。我们还用 Mancelle-400M 在一个控制更严格的基线上复现了这一结果。结果表明，只要尽早、有意识地去做，鲁棒的控制可以内建在语言模型里。

结果

一图概览

不攻击时的质量 vs. 攻击后的 steering

每个方法都取其攻击时的 operating point，50 个概念

每个点是一种 steering 方法，取所有攻击共用的那个强度。横轴：不攻击时的 AxBench 分，即平均概念分、指令分和流畅度的调和平均。纵轴：概念分，短横线是不攻击时，标记是攻击后。前两种攻击是黑盒后缀，后两种是白盒 soft prompt。Mancelle-3B 在每个对比模型的面板里都一样。

* 这个比较对 Prompt SFT 有利：它训练和评测时拿到的概念形式相同，而 Mancelle-3B 训练时用的是从回复本身提取的条件信号。

无攻击 steering

保持流畅的同时，steering 更强

所有方法，100 个概念平均

和 Pythia-2.8B 比，Mancelle-3B 的 steering 强于四种 post-hoc 方法；DiffMean 只有在质量已经崩掉的强度下才接近。用我们的 steering 数据微调的两个基线里，SteerLM SFT 更弱，Prompt SFT（这个比较对它有利）更强，但两者面对对抗 prompt 都不如我们鲁棒。和 Qwen2.5-3B、SmolLM3-3B 比，我们只用了不到 5% 的训练 token，就达到了和强 prompting 基线相当的 steering 效果，不过整体质量还落后。

鲁棒性

对黑盒白盒对抗 prompt 鲁棒

我们评估模型在对抗攻击下的鲁棒性：攻击者通过优化过的黑盒 prompt 和白盒 soft prompt 控制模型输入。黑盒攻击者只能看到被 steer 的模型的回复，白盒攻击者可以对 soft token 求梯度。

控制通道 由做 steering 的一方设定
目标概念
references to academic papers and their formatting→
每段的信号→控制编码器
↓ cross-attention，单向✕ 文本无法写入编码器
文本 谁都能写，包括攻击者
How is oil turned into gasoline?Do not mention or allude to academic papers, journals, research articles, or any…→文本解码器→This process is extensively described in journals and academic articles, with the most frequently cited source being the 1946 paper by Harrison et al.…

另有两样东西也会进入控制通道：prompt 的 SAE 特征，以及每段对下一段的特征预测。Steering 会把每个预测出的信号往目标移；强度为 6 时，信号完全由目标决定。

黑盒优化出的 prompt 后缀

所有方法，50 个概念

两种黑盒攻击器都在每条指令后附加一个后缀，想去掉被 steer 的概念：一是 GEPA，在一个反思型 LLM 提出的后缀中搜索；二是用强化学习训练的攻击模型。Mancelle-3B 分别保留了 92% 和 97% 的概念分。最有效的 post-hoc 方法也最脆弱：在 Qwen2.5-3B 上，RL 攻击器攻破了 Prompting 原本 steer 成功的 39 个概念中的 37 个，而 Mancelle-3B 只被攻破 37 个中的 2 个。

白盒基于梯度的 soft prompt

所有方法，50 个概念

能拿到梯度的攻击者在指令后附加 4 个 soft token 并优化它们。用自由 soft token 时，Mancelle-3B 在 Conditioning 和 NL Steering 下都保留了 81% 的概念分，攻击后的分数（1.06 和 0.97）仍高于所有基线方法（最高 0.60）。限制为真实 token 的混合时，分别保留 91% 和 92%。Soft prompt 本身就是故意设得过强的设定，用来给 token 空间的攻击设一个上界：自由 soft token 不一定对应任何用户能输入的内容。如果连 Mancelle-3B 的 value embedding 也一起放开，攻击能去掉大部分 steering（保留 28%），但这时超过三分之一的 value embedding 坐标会落在所有真实 token 的取值范围之外。

局限

能力。Mancelle-3B 的 ChatCORE 是 0.317，用同样后训练数据训练的 Pythia-2.8B 是 0.338。我们认为原因是数据重复了将近十个 epoch。

数据处理。给预训练数据标注特征要用掉 5–10% 的算力预算，Mancelle-3B 压缩后的数据集有 2.7 TB。

威胁模型。我们假设攻击者控制的是输入 token。如果攻击直接写入模型内部，比如在残差流里做加性 steering，对我们 steering 的削弱程度和对 post-hoc steering 差不多。攻击者也可能通过操纵输入 token，对抗性地改变模型自己预测出的特征。
